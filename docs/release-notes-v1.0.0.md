# EM4 Debug 1.0

The first downloadable Windows package for the Steam edition of **911 First Responders / Emergency 4**.

Download `EM4-Debug-v1.0.0-win32.zip`, extract it, close the game, and double-click **Install EM4 Debug.cmd**. The setup wizard detects common Steam locations, accepts a custom game folder, and can install, update, or remove the plugin. No compiler is required.

The package includes the in-game diagnostics menu, performance graph, log viewer, snapshot, Unit Inspector, 3D map paths, F11 window controls, automatic texture and model reload, and opt-in Ctrl+F7 command-script reload. Live command-script reload is experimental. Mission scripts are not recompiled. The game remains limited to its original four multiplayer players; this release does not include a player-count expansion.

The setup preserves game configuration, mods, logs, and reload settings. It refuses to overwrite unrelated DLLs or an installation whose recorded hashes no longer match. It is built for the verified 32-bit Steam game; other executables have not been validated.
